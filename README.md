## 这是什么

一套结构化的个人上下文，用来让不同的 AI 工具（WorkBuddy / Codex / Claude / ChatGPT 等）
在**不用我每次重复交代**的前提下，快速知道我是谁、我怎么做事、我在做什么、踩过哪些坑。

内容会持续更新，更新即生效。
